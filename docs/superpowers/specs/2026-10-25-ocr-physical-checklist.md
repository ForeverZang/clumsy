## E. 微信式选窗遮罩（Task 5/6，2026-10-27 追加）

入口：选定应用后点「选择窗口…」进入全屏 FRAME；在高亮窗口上拖框进入
DRAG；底部浮动工具条 = 撤销上一个框 / 重选窗口 / 取消 / 完成。

14. **0 窗口**：目标应用无可见顶层窗口（全部关闭/最小化）时点「选择窗口…」
    → 不进入遮罩，按钮行内红字提示该应用没有可见窗口。
15. **单窗口自动锁定**：目标应用只有一个可见顶层窗口 → 进入遮罩后无需
    点击，该窗口立即高亮（其余屏幕压暗），提示文案为「在亮框窗口内…」。
    自动证据：`tests/manual_ui.exe pickwindow` 在锁屏环境下已跑通
    自动锁定→拖框→完成→提交（日志 `regions=1`）；像素观感仍需人眼。
16. **多窗口悬停 + 点击锁定**：目标应用开两个顶层窗口（双击两次夹具）→
    移动鼠标时仅悬停窗口高亮，点击后锁定该窗口；**重点：另开一个其他
    程序的窗口（记事本/浏览器），鼠标悬停/点击它均无反应、绝不会被
    框选**（遮罩只认目标应用进程的顶层窗口）。
17. **连拖多框 / 撤销 / 重选**：在锁定窗口内连续拖 3 个框（每个 ≥10px，
    太小的不出框），工具条「完成」显示框数；撤销依次删框；点「重选窗口」
    回到 FRAME 后**本次新拖的框全部丢弃，已存在的旧区域保留**，再次锁定
    后旧区域仍在。
18. **完成门**：首次无任何框时「完成」灰色禁用；对已选过窗口、已有旧
    区域的情况点「+ 添加区域」进入遮罩后一个新框都不拖，「完成」可点
    （语义为保留旧框、不新增）。
19. **Esc / 右键**：FRAME 阶段 Esc 或右键 = 整体取消，回到主界面且无任何
    改动；DRAG 阶段右键取消正在拖的那一个框（已完成的框保留），Esc 退出
    整个遮罩；工具条「✕ 取消」与 Esc 等价。
20. **拖框中目标窗死亡**：拖框过程中关闭目标窗口（或最小化）→
    300ms 内遮罩自动退出，主界面红字「目标窗口在选择过程中关闭或
    最小化，请重新选择」，已选窗口被清空，不残留高亮层/工具条。
21. **多显示器**：遮罩只覆盖「进入瞬间光标最近」的那块显示器的工作区
    （不含任务栏），另一块显示器不压暗、其中的窗口照常可操作、绝不会被
    误选；要选另一块屏上的目标窗口时，先取消、把鼠标移到该屏再点
    「选择窗口…」。在两台显示器交界处拖框，框始终被夹在锁定窗口客户区内。
22. **展开态添加区域不跳动**（Review Focus #5）：第⑤块保持展开，
    连续两次「+ 添加区域」并取消，主对话框位置/大小不发生可察觉跳动。
23. **观感**：高亮描边、压暗透明度、框线与工具条在 100% 与 150% DPI 下
    都清晰不错位；拖框时尺寸提示（宽 × 高）跟随光标；高 DPI 下提交的
    区域仍按客户区比例归一化（与第 6 项一致）。

## F. 规则组 AND 真机（Task 1/2，2026-10-27 追加）

24. **双保险不切档**：建组含 R1、R2 两个成员（AND），阈值连续 2 帧。
    用窗口遮挡 R1 或 R2 其中一个区域一个识别间隔 → 该组冻结为
    UNAVAILABLE，不切档、不写 loss_change；恢复后重新计帧。
25. **连续 N 帧才切**：只满足 1 帧（闪烁文字）不切档；连续满足第 2 帧
    才按组内档位切丢包；消失沿同理。单帧误判不动作。
26. **同 tick 两组**：配置两个组在同一帧同时满足 → 时间线/CSV 里
    `rule_trigger` 每个触发组各一行（group:1、group:2），但 `loss_change`
    只发一次，档位取表序靠前的组；实际丢包率与该档位一致。
27. **同区域多关键词 OR**：一个成员内关键词用英文逗号分隔（如
    `重连,reconnect`），命中任一即该成员满足；CSV 触发文本以
    ` | ` 连接各成员 OCR 文本，逗号/引号保持 RFC4180 转义。
28. **删区域联动**：删除一个被组引用的区域（先弹确认框）→ 引用它的
    组成员被一并移除，组内其余成员的区域序号自动前移不错位；某组因此
    变成 0 成员时，组表该行显示空组内联错误，开始影响被拒绝；
    再次添加成员后恢复。
